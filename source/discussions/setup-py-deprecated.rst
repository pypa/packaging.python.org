===========================
Is ``setup.py`` deprecated?
===========================

No, :term:`setup.py` and :ref:`setuptools` are not deprecated.

Setuptools is perfectly usable as a :term:`build backend`
for packaging Python projects.

Only invoking ``python setup.py <command>`` directly is deprecated. For more
details on that topic, please see:

* `Why you shouldn't invoke setup.py directly <https://blog.ganssle.io/articles/2021/10/setup-py-deprecated.html>`__
  by Paul Ganssle
* :doc:`setuptools:deprecated/commands`
