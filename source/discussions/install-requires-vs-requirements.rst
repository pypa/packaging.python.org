install_requires vs requirements files
======================================

For documentation on these topics, see:

* ``install_requires``: `Declaring required dependency`_ in the setuptools documentation.
* :file:`requirements.txt`: `Requirements File Format`_ in the pip documentation.

This page previously explained abstract versus concrete requirements. For an
explanation of that distinction, see `setup.py vs requirements.txt`_ by Donald
Stufft.
